# HTML Movie Ranking Project

A simple movie ranking webpage built with HTML.

## Overview

This project displays a curated list of movies using basic HTML structure.

## Features

- Movie ranking list
- Simple HTML layout
- Beginner-friendly structure

## Technologies

- HTML5

## Project Goal

The goal is to practice HTML headings, lists, links, and page structure while building a small movie-themed webpage.

## Learning Outcomes

- Understanding semantic HTML
- Creating structured content
- Organizing a basic webpage

## Structure

The page is organized around a clear heading and movie ranking content, keeping the markup simple and easy to understand.
